# Lindenbach – Dorf-App

Gemütliches Dorfaufbau-Spiel, bei dem echte Bewegung (Apple Health) die Ressourcen liefert.

- `index.html` – spielbarer Web-Prototyp (Deutsch/Englisch), z. B. mit VS Code „Live Server“ öffnen
- `Spieldesign-Dorf-App.md` – vollständiges Spieldesign
- `CLAUDE.md` – Regeln für Claude Code
- `Prompt-Fahrplan.md` – Prompts für die iPhone-App
